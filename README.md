# CIS 2336 - Homework 0: My First Webpage

**Estimated time:** 30 minutes  
**Topics:** Basic HTML and CSS

## Goal

Create a simple one-page website that introduces you and demonstrates the HTML and CSS skills covered during the first three hours of class.

## Instructions

1. In the `Code` folder, create a file named `about-me.html`.
2. Create a separate stylesheet named `about-me.css` in the same folder.
3. Connect the stylesheet to your HTML file with a `<link>` element.
4. Add all of the following content to the webpage:

   - A page title inside the `<title>` element.
   - One main heading containing your name or a nickname.
   - One smaller heading, such as **About Me**.
   - A paragraph with two or three sentences about yourself.
   - An ordered or unordered list containing at least three hobbies, favorite foods, classes, or goals.
   - One image with a useful `alt` description. You may use a local image or an image URL.
   - A footer containing your name and the current year.

5. In `about-me.css`, add styles that:

   - Change the page's background color.
   - Change the main heading's text color.
   - Change the paragraph's font size.
   - Style one element using a class selector.
   - Style one element using an ID selector.

6. Open `about-me.html` in a browser and confirm that the content and styles appear correctly.

## Example File Structure

```text
Code/
|-- about-me.html
|-- about-me.css
`-- images/          (optional)
```

## Submission

Submit or commit the following files:

- `Code/about-me.html`
- `Code/about-me.css`
- Any local image used by your webpage


## Before You Submit

- Check that both files are saved in the `Code` folder.
- Make sure the image loads.
- Make sure the CSS styles are visible.
- Check that every opening HTML tag has the appropriate closing tag.
